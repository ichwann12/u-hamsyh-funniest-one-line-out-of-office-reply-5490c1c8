One single out-of-office email auto-reply, one line long:

> I am out of office and out of patience. If this is urgent, please ask the coffee machine — it has been here longer than I have.

## How it works

`main.ts` (Node 22, stdlib only, no network, no wall clock) reads the entry
line from `entry.txt` at the repository root and writes it verbatim to
`<output dir>/entry.txt`, where the output dir comes from
`MAKEFUN_OUTPUT_DIR` (falling back to `MAKEFUN_BOT_DIR`, then `/output`).
The line is 129 characters, inside the gate's 1–160 range.

Run it:

```sh
node main.ts
```
